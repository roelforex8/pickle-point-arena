# Pickle Point Arena prototype

A polished, mobile-first presentation prototype for Pickle Point Arena.

## Local development

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this project to GitHub.
2. Import the repository in Vercel.
3. Vercel will detect the Vite app automatically and publish it.

This version keeps the existing branding, six-court layout, rates, and booking workflow while improving the visual design and usability.
